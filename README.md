# 👥 HR Analytics Dashboard | Tableau

**Author:** Shruti Kumbhare
**Tool:** Tableau
**Domain:** HR Analytics · Workforce Planning · Attrition Analysis


## 🎯 Project Overview

An interactive Tableau dashboard that analyzes workforce data for **8,950 employees** to help HR teams understand **hiring, attrition, diversity, compensation and performance** in one view. It helps HR answer:

- How many employees have we hired, how many are still active, and how many have left?
- What is our attrition rate, and is it a concern?
- Which departments hire the most, and how is the workforce split by gender and location?
- How do salary, age group, education level and performance relate across the workforce?

## 🧩 Dashboard Features

- **Headcount KPIs:** total hires, active employees, terminations, attrition rate
- **Hiring and workforce trends** across 7 departments
- **Gender and geographic analysis** of the workforce
- **Salary and compensation analysis**
- **Age group and education level breakdown**
- **Employee performance analysis**
- **Interactive filters** so HR can slice the data by department, location and more for data-driven decisions
